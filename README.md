# Objectif 2026 🎯

Une application de tableau de bord personnel moderne conçue pour vous aider à atteindre vos objectifs d'ici 2026. Suivez vos habitudes, surveillez vos statistiques et restez motivé grâce à un système de progression gamifié.

![Aperçu de l'interface](public/icon.png)

## ✨ Fonctionnalités

- **📊 Tableau de Bord Intuitif** : Suivi quotidien de vos activités et habitudes en un coup d'œil.
- **📈 Statistiques Détaillées** : Visualisez votre progression avec des graphiques clairs (activités, humeur, complétion).
- **📅 Vue Calendrier** : Naviguez dans votre historique pour voir vos notes et réalisations passées.
- **📝 Journal & Humeur** : Notez vos pensées quotidiennes et suivez l'évolution de votre état d'esprit.
- **🏆 Gamification (Aura)** : Débloquez des badges et augmentez votre "Aura" en restant constant.
- **🎯 Gestion d'Objectifs** : Définissez et suivez des objectifs hebdomadaires et mensuels.
- **⚙️ Personnalisation** : Thèmes sombres/clairs, notifications de rappel et configuration flexible.

## 🛠️ Stack Technique

Ce projet est construit avec des technologies web modernes pour assurer performance et expérience utilisateur fluide :

- **Framework** : [React](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **Styling** : [Tailwind CSS](https://tailwindcss.com/)
- **Composants UI** : [Radix UI](https://www.radix-ui.com/) & [Lucide React](https://lucide.dev/) (Icônes)
- **Animations** : [Framer Motion](https://www.framer.com/motion/)
- **Graphiques** : [Recharts](https://recharts.org/)
- **Gestion de Date** : [date-fns](https://date-fns.org/)

## 🚀 Installation et Démarrage

Assurez-vous d'avoir [Node.js](https://nodejs.org/) installé sur votre machine.

1. **Cloner le projet**
   ```bash
   git clone https://github.com/NickHGA/Objectif2026.git
   cd Objectif2026
   ```

2. **Installer les dépendances**
   ```bash
   npm install
   ```

3. **Lancer le serveur de développement**
   ```bash
   npm run dev
   ```

4. **Construire pour la production**
   ```bash
   npm run build
   ```

5. **En ligne**
   ![Vercel](https://vercelbadge.vercel.app/api/nickhga/objectif2026)
   https://objectif2026.vercel.app/
